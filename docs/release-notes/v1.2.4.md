## What's new in v1.2.4

- **New logo.** The app icon and website logo now use the new deer artwork.
- **Deleting a transaction asks first.** Swiping a transaction in History no longer deletes it instantly; a "Delete this transaction?" dialog appears first, so an accidental swipe costs nothing.
- **Undo now works.** Previously, tapping Undo after a delete did not bring the transaction back. It now restores it along with its tags.
