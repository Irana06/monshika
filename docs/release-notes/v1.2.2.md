## What's new in v1.2.2

- **The More screen is genuinely compact now.** The v1.2.0 fix only trimmed a little, because the real cause was the menu tiles taking their height from a width ratio rather than from their contents. The layout now sizes itself to the icon and label.
- **The balance card follows the new palette.** Its gradient was still the navy blue of the old theme, clashing with the warm brown. It is now warm brown in dark mode and washi cream in light mode.
