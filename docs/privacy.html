Kebijakan Privasi

Berlaku sejak 10 September 2026

Ringkasnya: semua data keuanganmu tersimpan di HP-mu sendiri. Monshika tidak punya server, tidak memakai iklan, tidak memakai analitik, dan tidak menjual atau membagikan data kepada siapa pun.

1. Data yang disimpan

Monshika menyimpan data yang kamu masukkan: dompet, transaksi, kategori, budget, target, utang/piutang, jadwal berulang, cicilan, catatan Kakeibo, foto struk, dan pengaturan aplikasi. Semuanya tersimpan secara lokal di penyimpanan internal HP dan tidak dikirim ke server Monshika, karena Monshika tidak punya server.

2. Backup ke Google Drive (opsional)

Jika kamu memilih login dengan Google untuk backup:

  • Monshika hanya meminta izin drive.appdata, yaitu akses ke folder tersembunyi khusus aplikasi di Google Drive milikmu. Monshika tidak bisa melihat, membaca, atau mengubah file lain di Drive-mu.
  • File backup dikirim langsung dari HP-mu ke Google Drive milikmu. Jika kamu mengaktifkan sandi backup, file dienkripsi dengan AES-256 sebelum diunggah.
  • Monshika memakai alamat email akunmu hanya untuk menampilkan akun yang sedang terhubung di dalam aplikasi.
  • Kamu bisa memutus koneksi kapan saja dari menu Backup, atau lewat pengaturan akun Google. Backup di Drive bisa dihapus dari aplikasi, atau lewat Google Drive › Setelan › Kelola aplikasi.

Penggunaan dan transfer informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

3. Koneksi internet lainnya

  • Kurs mata uang: aplikasi mengambil data kurs publik dari Coinbase dan currency-api (via jsDelivr / Cloudflare Pages). Permintaan ini tidak berisi data keuanganmu.
  • Font: font Google Fonts dapat diunduh saat pertama kali dipakai.

4. Izin aplikasi

  • Notifikasi: pengingat mencatat, tagihan jatuh tempo, dan peringatan budget. Semuanya dijadwalkan lokal.
  • Kamera / galeri: hanya saat kamu melampirkan foto struk.
  • Biometrik: untuk membuka kunci aplikasi. Data sidik jari/wajah tidak pernah diakses Monshika; verifikasi dilakukan oleh sistem Android/iOS.
  • Widget beranda: ringkasan data disimpan lokal untuk ditampilkan di widget. Nominal bisa disembunyikan dari pengaturan.

5. Menghapus data

Kamu bisa menghapus semua data dari Backup & Export › Hapus semua data, atau dengan meng-uninstall aplikasi. Karena data tidak disimpan di server Monshika, tidak ada salinan lain yang tersisa selain file backup yang kamu buat sendiri.

6. Anak-anak

Monshika tidak ditujukan untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data dari mereka.

7. Perubahan kebijakan

Kebijakan ini dapat diperbarui. Versi terbaru selalu tersedia di halaman ini.
